## 👨‍💻 About Me

I'm an early-career **Software Engineer** and final-year student at the  
**University of Information Technology — VNU-HCM (UIT)**, with all graduation requirements completed.

I enjoy working on software **end-to-end** — from understanding the actual problem and designing the solution to implementation, testing, optimization, and iteration.

My primary focus is **full-stack development**, particularly with **TypeScript, React, Next.js, Node.js, and .NET**.

Beyond implementing features, I care about:

### 🎮 Real-Time Multiplayer Game

A cross-platform multiplayer game created from a real need within my friend group and designed to work across different devices.

One of the interesting engineering problems appeared when a game session involved around **10 players**, where each player could interact with multiple image assets.

Instead of treating the problem only as a UI issue, I analyzed what information each client actually needed.

**What I worked on**

- Manage game state across multiple players and devices.
- Investigate unnecessary asset loading and rendering.
- Reduce client-side workload by exposing only player-relevant resources.
- Design game logic with future game modes in mind.
- Separate initialization logic to make the engine easier to extend.
- Test gameplay across mobile and desktop environments.

**Focus**

`Real-Time Systems` · `Performance` · `Architecture` · `Cross-Platform`

## 🧠 How I Approach Software Engineering

I prefer understanding the **problem first** rather than immediately choosing a technology or architecture.

My typical thinking process looks like this:

```text
Problem
   ↓
Understand users & constraints
   ↓
Design the simplest reasonable solution
   ↓
Implement
   ↓
Test behavior & edge cases
   ↓
Measure problems
   ↓
Improve the system
